Set up in under 3 minutes

1

Install the VSCARS CLI

Run this on the machine you want to control (your laptop or server)

# One-line install — works on macOS & Linux
curl -fsSL "https://your-domain/static/install-connector.sh" | bash
ℹ Installs the vscars command. Requires Python 3.9+ and pip. Windows users: use WSL or PowerShell with Python installed.
2

Create a free account

Every account gets machine access in beta — no credit card needed

  1. Open the app: /app
  2. Click Register and create your account
  3. You're automatically on the Beta plan — 5 AI requests/day + full machine access
✓ Beta accounts can connect their own machine. The server is a relay only — your files never leave your machine.
3

Generate your CLI API key

One key links the CLI on your machine to your account

  1. In the app, go to Plan & Billing (◬ icon in the sidebar)
  2. Scroll to CLI API Key and click Generate API Key
  3. Copy and save the key — it's shown only once
⚠ Save the key immediately — it cannot be retrieved after you close the page. If you lose it, regenerate a new one (this disconnects existing machines).
4

Connect your machine

Run these two commands on the machine you installed the CLI on

# Initialize with your server URL and API key
vscars init
→ Enter server URL:
→ Enter API key: vscars_…

# Start the connector (keep this running)
vscars start
✓ Connected — your machine appears in My Machines
ℹ Keep vscars start running in a terminal or tmux session. The connector maintains a secure WebSocket to the relay. Your machine must be on and connected.

Optional: run as a background service

# macOS (launchd)
vscars service install && vscars service start

# Linux (systemd)
vscars service install --systemd && sudo systemctl start vscars

Ready to control your machine from anywhere?

Your account is free. Your machine stays yours. The server is just a relay.
