Setup first, then login and control your machine

Free account gives access to the app and API, but remote machine control starts after you install and connect the local connector.

1. Install connector 2. Generate API key 3. Connect machine 4. Login and use app

Step 1: Install Connector (Easy)

Run this one command on your laptop/desktop:

curl -fsSL "https://your-domain/static/install-connector.sh" | bash

This installs the VSCARS connector command and validates prerequisites.

Step 2: Generate API Key

  1. Open the app and sign in: /app
  2. Go to Plan & Billing and click Generate API Key (Pro+ required for machine access).
Free plan supports AI chat only. Machine control requires Pro / Team / Self-Hosted.

Step 3: Connect This Machine

Initialize and start connector:

vscars init
# enter server URL and API key
vscars start

Keep this running. Your machine appears in My Machines once connected.

Step 4: Login and Play

  1. Open /app
  2. Go to My Machines and verify status is online
  3. Run commands/files from Terminal and Files views
