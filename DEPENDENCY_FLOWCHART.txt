KEY DEPENDENCY PATHS
─────────────────────────────────────────────────────────────────────────────

1. CLIENT REQUEST → AUTHORIZATION → TOOL EXECUTION
   ┌────────────────────────────────────────────────────────────┐
   │ HTTP/WS Request                                             │
   │    ↓                                                        │
   │ main.py route handler                                       │
   │    ↓                                                        │
   │ get_current_user() [auth.py] ← JWT validation              │
   │    ↓                                                        │
   │ check_permission() [trust.py] ← Tool permission check      │
   │    ↓                                                        │
   │ execute_tool() [tools.py]                                   │
   │    ├─ File operations (pathlib, os)                        │
   │    ├─ Git operations (subprocess, git_ops.py)              │
   │    ├─ Command execution (subprocess)                        │
   │    ├─ AI/LLM (requests, API keys)                          │
   │    └─ JARVIS NLP [jarvis.py]                               │
   │    ↓                                                        │
   │ Response (REST or WebSocket)                                │
   └────────────────────────────────────────────────────────────┘

2. AGENT EXECUTION FLOW
   ┌────────────────────────────────────────────────────────────┐
   │ cli.py start command                                        │
   │    ↓                                                        │
   │ agent.py (persistent WebSocket client)                      │
   │    ↓                                                        │
   │ Connect to relay server via WebSocket                       │
   │    ↓                                                        │
   │ Listen for tool_call messages (ping every 25s)              │
   │    ↓                                                        │
   │ executor.py (local tool execution)                          │
   │    ├─ File operations (same as server)                      │
   │    ├─ Command execution (same as server)                    │
   │    └─ Path validation (_resolve)                            │
   │    ↓                                                        │
   │ Send results back via WebSocket                             │
   └────────────────────────────────────────────────────────────┘

3. DATABASE DEPENDENCY
   ┌────────────────────────────────────────────────────────────┐
   │ ANY Module                                                  │
   │    ↓                                                        │
   │ database.py get_db() [dependency]                           │
   │    ↓                                                        │
   │ SQLAlchemy SessionLocal                                     │
   │    ↓                                                        │
   │ vs_code_controller.db (SQLite)                              │
   │    ├─ User (username, email, permissions)                  │
   │    ├─ CommandLog (execution history)                        │
   │    ├─ AgentTask (pending tasks)                             │
   │    ├─ LicenseKey (subscription)                             │
   │    └─ Other models...                                       │
   └────────────────────────────────────────────────────────────┘

4. BILLING PIPELINE
   ┌────────────────────────────────────────────────────────────┐
   │ User signs up                                               │
   │    ↓                                                        │
   │ billing/routes.py → POST /billing/subscribe                 │
   │    ↓                                                        │
   │ stripe_client.py → create_customer()                        │
   │    ↓                                                        │
   │ Stripe API → create subscription                            │
   │    ↓                                                        │
   │ Stripe Webhook → POST /billing/webhook                      │
   │    ↓                                                        │
   │ billing/license.py → generate_license_key()                 │
   │    ↓                                                        │
   │ billing/plan_limits.py → apply_plan_to_permissions()        │
   │    ↓                                                        │
   │ database.py → Save LicenseKey model                         │
   └────────────────────────────────────────────────────────────┘
